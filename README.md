# 专注番茄钟 · Focus Tomato

一个打开即用的番茄工作法网页应用：25 分钟专注 + 5 分钟短休 + 15 分钟长休，自动循环，数据保存在浏览器本地。

## 功能

- 三种模式一键切换：专注 25 分钟、短休 5 分钟、长休 15 分钟
- 每完成 4 个番茄自动进入长休，符合经典番茄工作法节奏
- 圆环进度与倒计时同步，浏览器标签页标题实时显示剩余时间
- 今日任务清单：添加、勾选完成、删除，刷新后不丢失
- 统计面板：今日专注次数、累计分钟、本周专注数、总番茄数
- 深色 / 浅色主题切换，状态记忆
- Web Audio 三音提示音，可随时静音
- 键盘快捷键：`空格` 开始/暂停、`R` 重置、`N` 跳过、`1/2/3` 切换模式
- 纯静态单文件实现，无任何第三方依赖与网络请求

## 运行

直接用浏览器打开 `index.html` 即可；也可以起一个静态服务器：

```bash
npx http-server . -p 8080
```

然后访问 `http://localhost:8080`。

## 技术说明

- 计时基于 `Date.now()` 绝对时间戳，而非累加 `setInterval`，切到后台再回来不会走偏
- 状态通过 `localStorage` 持久化，键名 `focus-tomato-v1`
- 进度环使用 SVG `stroke-dasharray/stroke-dashoffset` 实现
- 全部逻辑内联在 `index.html`，便于分发与二次修改
